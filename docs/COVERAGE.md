# 學校收錄範圍

本目錄依教育部 114 學年度大專校院名錄與校別學生數資料盤點，並另納入中央警察大學、國防大學及國防醫學大學。更新日期：2026-11-23。

- 已建立 122 所可套用 preset：國立／軍警校 46 所、私立 76 所。
- 每校 preset 只寫入官方文件可確認、且目前 schema 能表達的差異。官方僅提供送存說明或將格式交由系所決定時，preset 只提供校名，並在檔頭標示 `name-only` 或 `department-defined`。
- 官方規範原件或可重現的 HTML 文字快照收在本目錄，來源 URL 與下載雜湊記錄於 `sources.lock.json`。

## 不適用

- 國立空中大學：教育部 114 學年度校別學生數沒有碩、博士班學生。
- 敏實科技大學：教育部 114 學年度校別學生數沒有碩、博士班學生；校方 2026 年公告亦以銜接其他大學研究所升學描述現況。

上述兩校仍在辦學，但目前沒有可套用的學位論文格式，因此未建立 preset。

## 停辦學校

教育部「退場學校」名單中的停辦學校不列入蒐集範圍。尚在辦學、僅停止招生或預定未來停辦者，不會因此誤列為停辦；只要仍有研究生與官方文件，仍納入本次盤點。
